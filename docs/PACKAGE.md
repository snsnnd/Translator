# 打包与分发指南（面向小白用户）

> 目标: 把整个工具交给一个完全不懂命令行的人，他只需 **解压 → 双击 install.bat → 双击启动**。
> 全程 **Windows 原生运行，不需要 WSL、不需要 Node、不需要 Python**（依赖已验证全部有 Windows 轮子）。

## 给使用者：安装三步

### 第 1 步 · 解压

把拿到的 `Translator-portable-xxx.zip` 解压到任意位置（如桌面）。

### 第 2 步 · 双击 `launch/install.bat`（只需一次）

自动完成: 安装 uv 包管理器 → 下载翻译依赖（首次约 3-10 分钟，看网速）。
黑窗口出现 `安装完成` 即可。

### 第 3 步 · 双击 `launch/启动翻译器.bat`

3 秒后浏览器自动打开 `http://localhost:8000`。
黑窗口**不要关**（关了=停止服务）；用完关窗口即可。

### 桌面快捷方式（一次设置）

右键 `launch/启动翻译器.bat` → `发送到` → `桌面快捷方式`，以后桌面双击即用。

### 第一次使用的配置

浏览器界面点 **设置** → 添加你的 API key（名称自取，如 `main`；没有 key 可联系作者购买）→ 回到书架上传 PDF → 开始翻译。

### 手机上使用

工具运行在电脑上，手机需与电脑同网（或通过 Tailscale 远程访问）:
1. 浏览器打开 `http://<电脑局域网IP>:8000`
2. 手机菜单 → `添加到主屏幕` → 获得带图标的"类 App"全屏体验 (PWA)
3. 注意: 局域网 IP 访问属于非 HTTPS 环境，PWA 安装与部分功能可能受限；
   完整手机体验推荐 Tailscale 组网（自带正规 HTTPS 证书，无需自签名证书）

macOS / Linux 用户: 运行 `launch/start.sh`，效果相同。

## 给作者：制作发布包

```bash
# 前置: 前端已构建 (cd web && npm install && npm run build)
./launch/make_release.sh
# → 生成 Translator-portable-<日期>.zip
```

脚本自动完成: 复制源码（**排除 .env / books/ / output/ 等密钥与版权内容**）+ 前端产物
+ 内置 Windows 版 uv.exe → 打 zip。
zip 内已包含构建好的 `web/dist`，**接收者不需要 Node，也不需要 WSL**。

**分发红线**（zip 排除项，勿手动塞回）:
- `.env` —— 含你的 API key（泄 key = 送钱）
- `books/` / `output/` / `prompts/book_prompt.txt` —— 含版权内容
- `.venv/` / `node_modules/` / `.git/` —— 体积巨大且平台相关

## 单文件 exe 可行性说明

当前架构（Python 多进程 + ONNX 模型运行时下载 + 子进程编排）打包成单 exe 的代价:
体积 1-2GB、模型仍需联网首跑、杀软易误报。**推荐路线**:
1. 现阶段: 便携 zip（本方案），已覆盖 95% 场景
2. 进阶: 用 Inno Setup 把 zip 包成 `setup.exe` 安装向导（体验≈原生安装包，制作 10 分钟）
3. 远期: Tauri/Electron 壳 + 内置 Python 运行时，实现真正的桌面应用 + 自动更新

## 常见问题

| 现象 | 处理 |
|---|---|
| install.bat 报网络错误 | 重跑一次（依赖从国内镜像/源下载，偶发超时）；或挂代理 |
| 双击启动一闪而过 | 先跑 install.bat；黑窗口上方有具体报错 |
| 浏览器打开报"无法访问" | 服务器还没起完，等 5 秒刷新；或看黑窗口报错 |
| 翻译没反应 | 设置页检查 key；扫描版 PDF（无文字层）暂不支持 |
| 关了黑窗口再打开报端口占用 | 等待 2 秒再启动；或任务管理器结束残留的 python 进程 |
| 杀毒软件拦截 | 误报，加入白名单即可 |
